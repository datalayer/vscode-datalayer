# webview/test/ - Webview Tests

Test utilities and test files for webview components and services. Currently empty - test infrastructure is set up but tests are pending.

## Pure modules of the extension host (vitest)

- **localRuntimeDetect.test.ts** - `src/services/localRuntime/detect.ts`: where `loop` is looked for, the version read, each refusal naming the install line, the port parsed, the environment handed, the chat's local handle.
- **harnessCheck.test.ts** - `src/services/localRuntime/harnessCheck.ts`: the catalogue read from the route and from `loop harnesses`, each check's sentence, `setup` offered for the part it fixes, the credential from the secret storage second.
- **sessions.test.ts** - `src/chat/sessions.ts`: the rows of two places with their applications and lineage, the filters, the sentences, the team runs.
- **sessionVerbs.test.ts** - `src/chat/sessionVerbs.ts`: which runtime answers, the swap's choices and sentences, the clone's turn, the export's name, the refusal shown, the import's second try.
