# src/services/localRuntime/ - The Local Runtime

A local runtime is one `loop serve` (agent-runtimes) per workspace folder, started by the extension when a session or a Try asks for it, never at activation. A coding agent (Claude Code, Codex, any harness of the catalogue) then runs in that folder, behind the Shield, on the person's own machine. `loop` is a prerequisite, never bundled: `uv tool install 'agent-runtimes[shield]'`.

## Files

- **detect.ts** - Pure (no `vscode`, no child process): where `loop` is looked for (`datalayer.local.loopPath`, `PATH`, uv tool's and pipx's bins — `candidateLoopPaths`), the version read from `loop --version` (`versionOf`, `compareVersions`), the verdict with its refusal sentences naming the install line (`loopDetection`: absent, too old, unanswered), the arguments of the start (`LOOP_SERVE_ARGUMENTS`), the port read from the server's lines (`portOf`), the environment handed (`runtimeEnvironment`: the trimmed set, the harnesses' declared credentials by name from the environment first and the secret storage second, the folder as `AGENT_RUNTIMES_WORKSPACE_ROOT`, the file session store, the person's token and IAM when signed in), and the chat's handle for a local place (`localRuntimeHandle`). Tested by `webview/test/localRuntimeDetect.test.ts` (vitest).
- **harnessCheck.ts** - Pure: the harness catalogue read from the runtime's `GET /api/v1/harnesses` (`harnessesOf`) or, until the installed release serves it, from the table `loop harnesses` prints (`parseLoopHarnesses`, boxed to be replaced); what `agent-shield setup --harness <id>` checks, checked here (`harnessCheck`): the binaries and Node's version against the register, the pinned adapter in the Shield's prefix, the credential in the environment or the secret storage, the terms (`termsRefusal`: an API-key-only harness refuses a subscription login in the register's words); each unmet part a sentence, `setup` offered for the part it fixes. Tested by `webview/test/harnessCheck.test.ts`.
- **localRuntimeService.ts** - `LocalRuntimeService` (a `BaseService` of the container, `ILifecycle`): finds `loop` (`detect`), starts a folder's runtime (`ensureRunning`: the port from its first line that names one, `/health` awaited, its output in the _Datalayer: Local runtime_ channel), lists them (`list`, `handles` for the chat), stops them (`stop`, on deactivation and when the folder closes), reads the harness catalogue (`harnesses`) and what the machine has for one (`machineOf`), keeps a credential in `context.secrets` (`credential`, `storeCredential` — never in settings, never logged). Refuses with `LocalRuntimeRefused`, whose sentence the commands show with _Copy the install line_.
