# src/test/providers/ - Tree Provider Tests

Tests for VS Code tree data providers.

## Files

- **settingsTreeProvider.test.ts** - Tests SettingsTreeProvider tree item generation and authentication-aware section rendering.
- **sessionsTreeProvider.test.ts** - Tests SessionsTreeProvider with stub sources: the places, a place's sessions grouped by application with each row's words, an unreachable place in one row, signed out, the filter, the team runs with their seats.
- **runtimesTreeProvider.test.ts** - Tests RuntimesTreeProvider tree item generation for runtime listing and management.
