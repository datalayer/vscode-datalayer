# src/chat/ - Copilot Chat Integration

Integration with VS Code's Copilot Chat for interactive AI assistance with Datalayer documents.

## Files

- **chatContextProvider.ts** - Registers a chat context provider that automatically makes notebook and lexical document content available to Copilot Chat when files are open in the editor.
- **datalayerChatParticipant.ts** - Chat participant providing interactive assistance with tool invocation for working with Jupyter notebooks and Lexical documents. Integrates with VS Code's language model API.
- **sessions.ts** - The Sessions view's rows (VS-04, VS-12), pure: the places (Datalayer, a local runtime of a folder), the list routes (`datalayerSessionsUrl`, `LOCAL_SESSIONS_PATH`), the rows read with their application (`listedSessionsOf`, `applicationOf`), the filter by application, state and title with the archived hidden (`filterSessions`, `filterSaid`), the grouping (`groupByApplication`), each row as `loop sessions list` prints it (`rowLabel`, `rowDescription`, `stateIconOf`, `contextValueOf`), the sentences (`placeProblemSentence`, `SIGNED_OUT_SENTENCE`, `NO_LOCAL_RUNTIME_SENTENCE`), and the team runs from the control plane's executions (`teamRunsOf`, `teamStateOf`, `executionsUrl`). Tested by `webview/test/sessions.test.ts`.
- **sessionVerbs.ts** - The seven verbs' pure parts (VS-05): which runtime answers for a session (`sessionTargetOf`: a local place unsigned, on Datalayer the runtime it runs on, signed), the swap's choices from the runtime's library (`swapChoicesOf`) and what is said before and after (`swapSentence`, `swappedSaid`), the clone's turn (`cloneTurnOf`), the export's file name (`exportFileName`), the refusal shown as the runtime said it (`refusalShown`), the import's second try (`importAsksForAgent`), the extension's two entries (`studioActivityUrl`, `localSessionFolder`), and the chat's open command (`OPEN_SESSION_COMMAND`, `OpenSessionRequest`). Tested by `webview/test/sessionVerbs.test.ts`.
- **appChat.ts** - A deployed application's agent in the Agent Chat sidebar (STUDIO A-18), pure (no `vscode`, no React, no network): the picker's choices from ai-agents' deployments (`deploymentChoicesOf`), the session API's AG-UI route (`agUiEndpoint`), the Appspec's host terms (`appHostOf`, `revisionRefusal`, `takesSignedUser`, `editorContextRefusal`), the user token ai-agents signs for a signed application (`fetchUserToken`, `withUserToken`, `isRunOf`), the `host_context` tool answered with the editor's open file (`hostContextTool`), the transcript's lines (`toolLineOf`), pending approvals (`pendingApprovalsOf`) and the URL prefixes the extension host signs for the view (`signedPrefixesOf`, `signsRequest`). Imported by `providers/agentChatViewProvider.ts` and `webview/agentChat/AppChat.tsx`; tested by `webview/test/appChat.test.ts` (vitest).
- **attention.ts** - What the editor says outside the chat about a session, pure: an approval's class (`actionClassOf`: `_class`, the ACP `_kind` mapped as the Shield maps it, else the tool's verb, else `write`), the notification's words (`approvalNotification`: the application, the action and its class, never the arguments), which approvals are notified (`newlyRaised`), the decision's rules (`decisionAllowed` once the chat has shown it, `stillPending` after reading it again, `decisionOutcome`: 409 _answered elsewhere_, 404 revealing nothing), the status bar's item (`statusBarItem`) and the finished turns of the sessions not in front (`finishedTurns`). Tested by `webview/test/attention.test.ts`.
- **sessionDisplays.ts** - A coding agent's displays in the editor, pure, on agent-runtimes' `portable/displays`: the display a tool's result carries (`displayOfToolCall`), a posted diff or terminal read strictly (`diffShownOf`, `terminalShownOf`), the diff view's documents and title (`diffDocumentPath`, `diffKeyOf`, `diffTitle`), the _after_ side's choice (`afterSideOf`: the disk when it holds what the agent wrote, byte for byte) and the terminal's writes from a sequence of displays (`terminalWrites`). Tested by `webview/test/sessionDisplays.test.ts`.
- **startHere.ts** - _Start a coding agent here_ (VS-06), pure: the folder's own instructions files kept and said (`ownInstructionsFiles`, `keptSaid`) or in the harness's way (`instructionsConflict`), the harness and application picks (`harnessPicks`, `appPicks`, the blank harness application `blankHarnessApp`), the configure and start requests (`configureRequestOf`, `startRequestOf`, `agentIdOf`, `sessionUidOf`), the runtime's refusal in a sentence (`runtimeRefusal`) and what the chat is handed (`startedSession`). Tested by `src/test/vitest/startHere.test.ts`.
- **apps.ts** - _Try it here_ (VS-11), pure: what a file is (`tryTargetOf`), the `loop apps run --web --watch` arguments (`tryArguments`), the served address and refusal read from `loop`'s lines (`servedAddressOf`, `refusalLineOf`), the Studio's Validate and Ship tabs (`studioTabUrl`), the push line and the panel's page (`previewHtml`). Tested by `src/test/vitest/apps.test.ts`.
